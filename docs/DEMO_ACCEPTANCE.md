## 可复现入口

`npm run tauri -- dev --no-watch -- --locked -- --demo`

仅调试构建支持 `--demo`。每次启动自动在系统临时目录新建独立 `worklog-demo-<UUID>`，包含 SQLite、DemoVault 和 DEMO-ONLY.txt；不读取正式数据库位置指针。窗口标题明确显示“隔离演示”和路径。演示数据保留，不自动删除。

夹具包含近 29 天的每日三项计划、完成状态和每日 90 分钟专注，两个具有前置关系的习惯、未结算的昨日/今日、一个 120% 金杯目标及一个无日期待办。夹具是合成事实，不能代替计时器和逐日计划的实际操作验收。

## 已实际操作并观察

- 启动 Windows 原生 Tauri 调试版，主页面读到隔离数据库的记录。

- 界面显示七日柱图、长期目标 120% 与金杯、清新浅色排版；滚动区域存在。
