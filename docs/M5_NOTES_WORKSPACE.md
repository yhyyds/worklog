# M5：随笔与 Obsidian 文件工作区

## 数据权威

随笔正文直接保存在 Obsidian Vault 的 Markdown 文件中，文件是唯一正文数据源。SQLite 只保存轻量索引并追加领域事件，不复制正文。

新建随笔时，今日日志仅追加：

```text
10:43：新建笔记《标题》
```

后续编辑事件为隐藏级别，不让每日回顾变得嘈杂。

## 能力

- 递归浏览 Vault 内最多 5000 个 Markdown 文件。
- 按标题和相对路径搜索。
- 新建随笔默认保存到 `随笔/YYYY/YYYY-MM/`。
- 编辑、分栏和预览三种模式，支持 GFM 表格、任务框和代码块。
- 支持点击 `[[Obsidian Wiki Link]]` 打开同名笔记。
- `Ctrl+S` 保存；覆盖前创建版本备份并使用原子替换。
- 每两秒检查当前文件的修改时间：没有本地草稿时自动载入外部修改；发生并发编辑时由用户选择版本。

## 文件安全

- 所有命令只接受 Vault 内相对路径。
- 拒绝绝对路径、父目录片段、非 Markdown 扩展名和 Windows 非法文件名。
- 解析后的真实路径必须仍位于 Vault 内。
- 符号链接与隐藏目录不会进入文件列表。
- 单篇笔记最大读取尺寸为 4 MB。
- Markdown 渲染默认不执行原始 HTML。
