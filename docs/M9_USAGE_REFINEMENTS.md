# M9 使用细节优化

## 目标

根据实际使用反馈，减少主页面跳动与重复操作，让任务维护、专注回顾和四象限浏览更顺手，同时继续遵守低噪记录原则。

## 交互调整

- “我的一天”始终是主页面。随笔、Obsidian、设置只打开弹窗，不修改主标题和导航选中状态。
- 父任务和子任务都可在任务卡片中编辑标题、添加、修改或取消当天计划时间段。
- 每个四象限右上角提供快捷新增按钮，自动带入该象限的重要性和紧急性。
- 每个象限拥有固定可视高度和独立纵向滚动条。
- 完成的父任务移动到所在象限底部；完成的子任务移动到所属父任务的子任务列表底部。显示编号和永久 ID 不变。
- 设置中可按 85%–130% 调整界面字号，配置即时生效并保存在本机。
- 修改番茄钟时长后，主页面空闲计时器立即同步显示。

## 专注约束

- 新建和切换专注时只允许选择一级任务。
- 暂停专注必须填写原因；原因作为不可变的 `focus.paused` 事件保存。
- 切换专注任务生成可见的 `focus.task_switched` 事件，同时记录切换前后的编号与标题。

## 每日日记

“今日记录”按番茄钟会话生成 Obsidian 原生可折叠的嵌套列表：

```markdown
- 第1轮任务，专注时段：10:00–10:25，任务：#2 整理资料，任务记录：
	- 10:00：开始一轮工作，任务内容：#2 整理资料
	- 10:08：暂停本轮工作：临时回复重要消息
	- 10:12：继续本轮工作
	- 10:18：本轮工作由#2 整理资料切换至#3 制作汇报
	- 10:25：完成一轮工作，共25分钟
```

父项与第一条时间轴之间不留空行，所有时间轴事件使用一个制表符缩进。Obsidian 会把它们识别为该轮任务的子内容并提供原生折叠，不需要 `<details>`、`<summary>` 或其他 HTML 标签。

不属于任何番茄钟时段的可见事件放入“非专注时段记录”。隐藏级事件仍不会进入日记。

## 数据兼容

本轮不修改既有任务 ID、每日编号或事件不可变规则。暂停原因和任务切换沿用事件表；历史数据库可直接升级。
