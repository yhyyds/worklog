# M6：番茄钟生命周期与 Windows 桌面集成

## 状态机

专注会话仍使用目标结束时间计算。专注正常或提前完成后，根据设置自动创建休息会话：

- 默认专注 25 分钟。
- 默认短休息 5 分钟。
- 每完成 4 轮进入 15 分钟长休息。
- 放弃专注不创建休息。
- 休息支持暂停、继续和跳过。
- 专注或休息处于活动状态时，禁止开启另一轮专注或执行日终收尾。

暂停、继续、休息开始与结束事件以隐藏级别保存，不进入日记；完整状态仍可用于后续统计。

## 后台校时

Rust 后台任务每秒检查一次目标结束时间。应用最小化、WebView 被节流、电脑锁屏或休眠恢复后，会根据绝对时间完成应有的状态迁移，不依赖前端持续递减。

状态迁移后向前端发送刷新事件，并通过系统通知分别提示：

1. 专注结束。
2. 休息开始。
3. 休息结束。

## Windows 集成

- 托盘左键打开并聚焦主窗口。
- 托盘菜单提供“打开 Worklog”和“退出”。
- 点击窗口关闭按钮时隐藏到托盘，计时继续。
- 全局快捷键 `Ctrl+Shift+W` 唤起窗口。
- 系统通知由 Tauri 通知插件发送；Windows 正式安装包中使用应用身份显示。
