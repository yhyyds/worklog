# 周报明细（1.0）

## 参考

- TickTick 官方介绍：逐日习惯状态、当前连续天数、累计天数，以及任务/专注/习惯分区。https://blog.ticktick.com/2020/05/22/a-healthier-life-with-ticktick-habit/
- Todoist 官方帮助：每日完成量、连续达标与最长连续、近四周的任务对比。https://www.todoist.com/help/articles/use-the-productivity-view-in-todoist-6S63uAa9
- Streaks：连续习惯记录。https://streaksapp.com/

采用以上信息组织思路，不复制产品素材。Worklog 保持次日回顾习惯，文学内容留在署名引语中；其他界面使用直接的名称、动作和数字。

## 统计定义

- 一周从周一开始；尚未结束时，与历史周相同天数比较。四周表格不与个人中位数的八周窗口混淆。
- 连续完成：可跨周；截至所看周的周末，当前周则截至昨天。若该日尚未回顾则显示待回顾，不给出伪造的 0 天或延续天数。
- 本周最长：只计算落在本周的连续完成天数。历史最长：只读取截至报告日期的历史，未来记录不影响旧周。
- 中断一次：确认完成后紧接着一天确认未完成；连续多天未完成只记一次中断。未知日期既不计失败，也不能拼接一条连续记录。
- 前置打卡没完成：自己已做但未达标，计入未完成；日历单独标记，不清除原始完成事实。
- 已停用习惯保留停用前的历史，新习惯开始前不计入计划。今天的习惯要在明天回顾，因此不算待回顾。
- 任务摘要和清单共用末级任务过滤条件，排除取消项和待办箱内未完成项。数据单位是每日任务安排，不混作永久任务数量。
- 轮次、均时和最长时长按已结束的专注轮计算，同一轮多个片段先合并；正在运行的轮不纳入均时。暂停和切换次数来自事件，不推断为效率下降。

## 图片

导出宽度固定，高度由同一绘图函数预计算。导出包含习惯逐日符号、连续/中断数据、专注统计、每日表格、四象限分布、全部任务清单、历史对比、当前目标与引语。长标题换行，不静默裁切。极端长图超过 30000 像素时明确报错，不保存残缺图片。

## 文案

主界面不出现“通过依赖”“不使用 AI”“不催促你”等产品实现说明或空泛表达。必要的统计口径放在折叠说明里；笔记未保存、文件冲突、备份和迁移提示保留。
