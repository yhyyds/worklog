# Worklog 1.4：专注关联、时间线归组与任务编辑

## 新建任务可取消

- 顶部“新建日程”、四象限快捷 `＋` 和父任务内“新建子任务”都提供明确的取消按钮。
- 取消只关闭并清空当前表单，不创建任务、不生成事件，也不影响已有任务。

## 想法跟随当前专注

- 存在进行中或暂停中的专注时，想法优先关联 `focus.taskId` 对应的一级任务。
- 切换专注任务后，想法区的“关联 #编号”立即更新；新记录不会继续使用开始专注前的旧选择。
- 没有专注时，继续使用用户选择的一级任务；未选择时回退到第一个未完成一级任务。

## 两分钟内时间线归组

- SQLite 中每条领域事件仍独立追加，永不修改、覆盖或删除。
- 界面和 Obsidian 只在读取投影时归组：当前事件与上一事件间隔小于 120 秒时沿用同一时间节点。
- 比较对象是相邻事件，因此连续的 119 秒间隔可以形成一个较长的记录组；恰好 120 秒必须新建节点。
- 界面组内逐行显示；Obsidian 使用中文分号连接。不同番茄钟轮次以及专注内/外记录绝不跨区归组。

## 主任务可修改象限

- 一级任务编辑时可以同时修改重要性与紧急性。
- 子任务不显示分类控件，后端也拒绝直接修改子任务分类。
- 一级任务移动象限时，同日直接子任务同步继承分类，保证后续日终顺延口径一致。
- 任务永久 UUID、当天编号、标题历史和既有事件不受影响。
