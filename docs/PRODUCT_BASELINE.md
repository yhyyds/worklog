# M1 产品执行基线

## 主界面

左侧导航固定为：我的一天、随笔、Obsidian、设置。“我的一天”同时呈现今日任务、当前专注、工作想法输入和今日记录，不再为专注与工作想法设置重复入口。

## 四象限

重要性与紧急性是两条独立轴：重要/次要、紧急/稍缓。任务可选工作时间段。父子任务最多两级；当天显示编号分配后不自动改变。

## 时间线降噪

- 新建、完成、任务切换、番茄钟完成和用户工作想法默认可见。
- 暂停、继续、排序和设置变更默认收进详情。
- 草稿级番茄钟笔记默认不进入最终日记。
- 同一事务产生的“完成旧任务 + 新建子任务”合并为一条回顾记录。

## 番茄钟记录分级

类型：进度、想法、决定、阻塞、结果。

回顾等级：关键、普通、草稿。关键内容进入摘要；普通内容进入详情；草稿仅在专注详情中保留。

## 跨日

日终只顺延未完成任务。父任务中已完成的子任务不复制；只保留未完成子任务。永久任务 ID 保持不变，第二天重新生成显示编号。

## Obsidian

目标路径：`<Vault>/<用户指定日记根目录>/YYYY/YYYY-MM/YYYY-MM-DD.md`；未指定日记根目录时直接使用 Vault 根目录。应用仅替换带版本标记的受管理区块，人工补充内容原样保留。写入前备份并使用临时文件原子替换。

## M1 验收

- 可以创建四象限任务并获得当天编号。
- 可以完成任务并自动生成时间线事件。
- 可以选择任务启动、暂停、继续和结束一轮专注。
- 可以写入带类型和回顾等级的工作想法。
- 页面刷新后浏览器开发模式数据仍然存在。
- SQLite 初始化可重复执行，事件表禁止更新和删除。
