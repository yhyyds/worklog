# Worklog 1.3：每日固定安排与记录降噪

## 每日固定安排

- “固定安排”位于四象限下方，用于会议、预约等必须在特定时段进行的当日事项。
- 每条记录必须填写内容、开始时间和结束时间，且结束时间必须晚于开始时间。
- 安排按开始时间排序，可修改；取消使用软取消，SQLite 原记录和追加事件均保留。
- 固定安排不是四象限任务，不参与任务完成率、番茄钟目标或历史未完成任务重新安排。
- Obsidian 日记的“今日安排”同时展示固定安排和带计划时间的任务。

## 任务事件文案

- 首次创建任务继续记录编号与标题：`新增任务#6.1：内容`。
- 状态变化只记录当天编号，例如：`完成任务#6.1`。
- 修改记录使用：`任务#6.1：变更为'变更后内容'`。
- 专注开始和切换仍保留任务标题，因为这些记录需要说明当时实际专注的内容。

## 待办与历史布局

- 弹窗宽度跟随可用视口，不再受旧的 880px 上限约束。
- 待办、历史卡片和表单使用可收缩网格；长标题、子任务和操作按钮可换行，不产生横向裁切。

## 数据与兼容性

- 新增向前迁移 `0010_daily_schedules.sql`。
- 迁移不修改或删除既有任务、事件、设置、数据库文件或 Obsidian 内容。
- 浏览器预览自动为旧的本地日状态补充空的固定安排集合。

## Windows 产物

- 日常 CI 与 Release 只构建 `Worklog_1.3.0_x64-no-webview2-setup.exe`。
- 不再构建内置 WebView2 版本或 MSI；目标电脑需已有 Microsoft Edge WebView2 Runtime。
- 同时生成 `SHA256SUMS.txt` 与 `BUILD-INFO.txt`；无代码签名证书时仍可能被 SmartScreen 或组织策略阻止。
